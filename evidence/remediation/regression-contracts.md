# Minimal remediation contracts (not new qualification axes)

- HG-01: invariant class, requiredness and criticality come from the existing catalog. Dossier criticality must equal it, including false→true changes. No assessor can override catalog criticality.
- HG-02: this alpha's environment and task arrays specify the complete supported combination: require equality of sets (both containment checks). Exclusions remain a superset of required exclusions and disjoint from claims. Ordering is accepted; duplicates reject.
- HG-03/HG-05: qualification support is the union of explicit required records, required invariant support, every required oracle check and its observation support, all behavioral support and assessor review support. Missing references reject; an explicit missing execution yields NOT_RUN and cannot verify.
- HG-04: not_tested permits only ABSENCE_OF_EVIDENCE; dynamic tools permit OBSERVATION/COVERAGE; rustc/formal permit PROOF/OBSERVATION/COVERAGE with explicit assumptions for PROOF. Other review/document methods permit OBSERVATION/COVERAGE. These restrictions do not imply epistemic status.
- HG-06: submitted oracle labels are ASSERTED_RESULT. The engine emits DERIVED_RESULT after checking observation bindings and executing fixed evaluators. A negative asserted result is conservatively retained as a safety veto; it never changes the evaluator's outcome. Submitted NOT_RUN also prevents verification. Results bind observation, candidate reference, evidence and oracle definition hashes. Hashes authenticate neither candidate truth nor humans.
- HG-07: only the frozen nine-state teardown sequence, resource-liveness snapshots, classification equality, strength classification and structured defect observations are evaluated. No expression language, code execution, network, or kernel execution. An unsafe supplied trace always fails irrespective of its submitted PASS/BLOCKED label. Asserted facts can still be dishonest; external artifact authentication remains OPEN.
- Hashing: preserve the existing complete-record hash (explicit input timestamp and limitations included). Formatting and key order are presentation-only; changing recorded facts changes the hash. No current time participates.
- Prior evidence is immutable. Canonical alpha fixtures will receive explicit structured synthetic observations; they remain synthetic. Updated schema/rules version is documented, not silently backfilled for arbitrary input. Frozen old dossiers lacking provenance reject; semantic regressions also transplant only the new provenance fields to exercise the original bug under the new contract.
